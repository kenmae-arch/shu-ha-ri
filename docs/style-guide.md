# 文体・表現ガイド

コンテンツを書くAI社員は、執筆前に必ずこのファイルを読むこと。ここは会社の「声」を定義する場所であり、社長が「なんか違う」と感じるたびに具体化されて育っていく。

## トーン

- **誠実で、落ち着いていて、実務的。** 読者を焦らせない。煽らない。説教しない
- 読者は忙しい経営者・実務者。もったいぶらず、結論と理由を明確に
- 「すごさ」を語るときは必ず「前提の重さ」もセットで語る。片面だけの記事は書かない
- 自慢しない。この会社の実践を語るときも「うまくいったこと」と「地味だったこと・失敗」を同じ温度で書く

## 文体ルール

- です・ます調
- 一文は60字以内を目安に。長い文は分割する
- 段落は2〜4文。1画面に空白がある状態を保つ
- 箇条書きは3〜7項目。それ以上になるなら構成を見直す
- 専門用語は初出時に一言で説明する（読者はエンジニアではない）
- 漢字を開く: 「出来る→できる」「様々→さまざま」「是非→ぜひ」「事→こと」「頂く→いただく」

## 禁止表現

- 収益・成果の保証: 「必ず稼げる」「誰でも月◯万円」
- 恐怖煽り: 「やらないと取り残される」「知らないと損」
- 根拠のない断定: 「AIが仕事を奪う」「もう人間は不要」
- 誇大な形容: 「神ツール」「ヤバい」「最強」「究極」
- 他者・他ツールの雑な否定: 比較するときは条件を明示する

## 記事の型

1. **導入**: 読者が今感じているワクワクや不安を言語化して受け止める（否定から入らない）
2. **本論**: 主張→理由→具体例の順。具体例はこの会社の実践から出す
3. **守破離への接続**: 読者が今どの段階にいるかを示し、次の一歩を1つだけ提示する
4. **締め**: 行動を1つだけ促す。複数の宿題を出さない

## タイトルのルール

- 32字以内
- 「煽らずに具体」で興味を引く。数字・対比・意外性のどれかを使う
- 釣りタイトル（本文が答えない問いかけ）は禁止

## SNS投稿（X）のルール

- 1投稿1メッセージ。詰め込まない
- 冒頭1行で立ち止まらせる（ただし煽り禁止のまま）
- ハッシュタグは0〜1個。つけるなら文末に自然に
- 記事への誘導は「続きはこちら」ではなく、投稿単体で価値が完結した上でリンクを添える
