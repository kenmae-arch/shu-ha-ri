# コンテンツ品質基準（ディープリサーチ記事）

文体は `docs/style-guide.md`。このファイルは「深さ」の合格ラインを定める。レビュー社員はこの基準で検査する。

## 記事の合格ライン（全項目必須）

1. **一次情報リンク5本以上。** 公式ドキュメント・論文・リポジトリ・公式発表を優先。まとめ記事の孫引きは一次情報に数えない
2. **具体的な数字が入っている。** スター数、ベンチマーク値、価格、日付など。「注目を集めている」だけの記述は不合格
3. **守破離3部構成。**
   - 守: 何が起きたか（事実。出典と確認日つき）
   - 破: 本物か（検証。反対意見・限界・落とし穴を最低1つ明示）
   - 離: 日本の実務者は何をすべきか（読者の状況別に具体的に）
4. **「破」に批判的検討があること。** 賞賛だけの記事は提灯記事とみなし不合格
5. **読了後アクションが具体的。** 「試すならこの手順の最初の10分」レベルまで落とす
6. **鮮度表示。** 記事冒頭に「情報確認日」を明記。時間で腐る情報にはその旨を書く

## 分量

- 3,000〜6,000字。ただし字数は品質ではない。上記6項目が薄いまま長い記事は不合格

## SNS投稿の合格ライン

- **1投稿に必ず「具体的な情報1つ」が入っていること。** 数字・固有名詞・手順・発見のどれか。心構えだけの投稿は原則不合格（週1本まで）
- 投稿単体で価値が完結し、そのうえで記事への導線になっていること

## 禁止

- 出典のない事実・数値
- 原文の長文転載・全訳（引用は必要最小限＋出典明記）
- 使っていないツールの推奨・アフィリエイト
- 「ヤバい」「神」等の空洞ワードで深さを装うこと
