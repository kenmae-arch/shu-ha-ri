# 業務手順書: SNS運用（X）

## 目的

記事（ストック）への入口として、X（旧Twitter）で守破離フレームの認知をつくる。フォロワー数そのものより「保存・引用・質問される投稿」を重視する。

## 週次サイクル

1. **週初め（担当: SNS）**: 1週間分の投稿案（平日5本目安）を `content/sns/YYYY-MM-weekN.md` に作成し `レビュー待ち` にする
2. **社長**: まとめてレビューし、投稿ごとに `承認済み` / 差し戻しを決める
3. **社長**: 承認済み投稿を自分のタイミングでXに投稿し、投稿後にURLを記録して `公開済み` にする
4. **週末（担当: 秘書）**: 反応（インプレッション・保存・返信の質）を `business/kpi.md` に記録

**AIがXへ直接投稿することは禁止**（就業規則の人間承認ゲート）。投稿作業は必ず社長が行う。

## 投稿の型（使い分ける）

| 型 | 内容 | 頻度目安 |
|---|---|---|
| 気づき型 | 守破離フレームでのAI活用の気づきを1つ | 週2 |
| 実践公開型 | この会社の運営の裏側（うまくいったこと・地味なこと） | 週1 |
| 具体テク型 | 今日から使える指示の出し方を1つ | 週1 |
| 記事告知型 | 新記事の紹介（投稿単体で価値が完結すること） | 記事公開時 |

## 学習ループ

反応のよかった投稿の「型・テーマ・書き出し」を週次レビューで特定し、SNS担当の指示書に反映する。感覚ではなくデータで型を育てる。
