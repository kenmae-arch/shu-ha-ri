# 業務手順書: 週次レビュー

会社の心臓。週1回15分。`/weekly-review` スキルがこの手順を実行する。

## 手順

### 1. 実績整理（担当: 秘書）

- 今週のコミット履歴・`content/` の変化から実績を集計する
  - 公開した記事・SNS投稿の本数
  - 進行中で止まっているもの（`レビュー待ち` のまま放置など）
- `business/kpi.md` に週次行を追記する（外部数値は社長への質問リストとして出す）

### 2. 社長への報告と質問（担当: 秘書）

以下の形式で簡潔に報告する。

```
## 今週のまとめ（YYYY-MM-DD）
- 実績: （公開本数・完了タスク）
- 停滞: （止まっているもの、その場所）
- 社長に必要な入力: （外部数値、承認待ちの一覧）
- 来週の候補: （backlogから3つまで）
```

### 3. 社長の判断

- 来週やる記事テーマ・投稿方針を決める（秘書がbacklogに反映）
- 今週いちばん差し戻しが多かった工程を1つ選び、その指示書またはstyle-guideを**1箇所だけ**改善する

### 4. 記録（担当: 秘書）

- 決定事項を `business/decisions/` に記録する（テンプレート: `templates/decision-record.md`）
- `business/backlog.md` の優先度を更新する
