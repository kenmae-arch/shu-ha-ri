## ブランドの核

- 一言でいうと: **英語圏の一次情報を、検証して、日本の実務へ**
- トーン: 落ち着いている / 誠実 / 煽らない / 実測主義
- 守破離の意味: 守=正確に読む、破=検証する、離=現場に応用する

## カラーパレット（全ビジュアル共通）

| 用途 | 色 | コード |

| 背景（ベース） | ディープネイビー | `#0F1B2E` |
| 線・文字 | オフホワイト | `#F2EFE9` |
| アクセント（1色のみ） | アンバー | `#C9822F` |

原則: 3色以外を使わない。グラデーション・立体感を使わない。フラットで幾何学的に。

## ビジュアルコンセプト

3本の水平線で守破離を表す。
- 1本目 = 連続した直線（守: 途切れない基準）
- 2本目 = 途中で切れた線（破: 検証によって割る）
- 3本目 = 切れた線がずれて外へ伸びる（離: 応用して出ていく）

## 画像生成の運用ルール

- **画像に日本語テキストを入れない。** 画像生成AIは日本語の字形を崩すため。文字が必要ならCanva等で後から重ねる
- 生成サイズ: Xヘッダー 1500×500px / アイコン 400×400px以上
- アイコンは64×64pxに縮小しても判別できることを条件にする（縮小して確認する）
