# 週次レビュー

`docs/workflows/weekly-review.md` の手順で会社の週次レビューを実行する。社長の時間を15分以上使わないこと。

## 進行手順

1. `secretary` エージェントに今週の実績集計・KPI更新・停滞検知を依頼する
2. 秘書の報告を、手順書の報告形式（実績 / 停滞 / 社長に必要な入力 / 来週の候補）で社長に提示する
3. 社長の判断（来週のテーマ、承認待ちの処理、改善する指示書1箇所）を聞く
4. 決定を `secretary` エージェントに渡し、backlogへの反映と `business/decisions/` への記録を依頼する

## 厳守事項

- 社長に求める判断は1回のレビューで3つまでに絞る
- 指示書の改善は1箇所だけ。複数直したくなったら残りをbacklogに積む
